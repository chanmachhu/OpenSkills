# AGENTS.md

Read `README.md` first: structure, skill fields, content and design rules, checklist.

Essentials:
- Adding or editing a skill = one file in `content/skills/<id>.json` (id = file name). Themes live in `content/themes.json`. Don't touch HTML/JS/CSS for content changes.
- Downloadable skills live unzipped in `content/downloads/<id>/`. Any change there needs a `version` bump in `content/skills/<id>.json`. Never commit zip files.
- Never edit `_site/`: it is generated by `node scripts/build.js`.
- Run `node scripts/build.js` after every change. It must end without `error:`.
- No dependencies, no build tools beyond Node stdlib, no frameworks.
- Content: English, short (one-sentence description, ~3 yes / ~2 not really), no commands, syntax or install steps, no "(n)" counters, no raw HTML in JSON. Unknown source → omit `source`/`contact` ("Ask Basile" is shown).
- Design: colors only via the CSS variables (each with a dark value), fixed px font sizes per breakpoint (never `vw`), check 390px mobile and dark mode.
- Links must stay relative: the site is served under `/OpenSkills/`.
